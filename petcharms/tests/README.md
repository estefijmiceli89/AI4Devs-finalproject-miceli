## Tests

Quick commands for each test level:

- Unit: `pnpm test:unit`
- Integration: `pnpm test:integration`
- E2E (headless): `pnpm test:e2e`
- E2E (single spec): `pnpm test:e2e tests/e2e/<spec>.spec.ts`
- E2E (UI): `pnpm test:e2e:ui`
- E2E (headed): `pnpm test:e2e:headed`

Coverage (unit + integration only): `pnpm test:coverage`
